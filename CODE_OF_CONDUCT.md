# Code of Conduct

GestureSense is maintained by **Saad Kamal**.

## Our Pledge

We want this project to be welcoming, respectful, and useful for people learning or building with browser-based computer vision.

Contributors and participants are expected to:

- Be respectful and constructive
- Assume good intent
- Give actionable feedback
- Avoid harassment, insults, or discriminatory language
- Keep discussions focused on improving the project

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment or threats
- Personal attacks
- Demeaning or discriminatory comments
- Publishing private information without permission
- Deliberately disruptive behavior

## Enforcement

The project maintainer, **Saad Kamal**, may remove comments, reject contributions, or restrict participation when behavior is harmful to the project or community.

## Reporting

If you see behavior that violates this code of conduct, please report it to the project maintainer.
